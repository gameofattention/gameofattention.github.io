# Learning Deep Learning

> **Source Book:** [Neural Networks and Deep Learning](http://neuralnetworksanddeeplearning.com/) by Michael A. Nielsen

This is our learning journey through the free online book **"Neural Networks and Deep Learning"** by Michael A. Nielsen. The goal is to explore, understand, and internalize the core concepts of neural networks and deep learning through structured notes, experiments, and reflections.

## 📖 About the Book

*Neural Networks and Deep Learning* is a free online book that teaches the fundamentals of:

- **Neural networks** — a biologically-inspired programming paradigm that enables computers to learn from observational data
- **Deep learning** — a powerful set of techniques for learning in neural networks

The book covers state-of-the-art solutions to problems in image recognition, speech recognition, and natural language processing.

## 🚀 Getting Started

This project is built with [mdBook](https://rust-lang.github.io/mdBook/).

```bash
# Install mdBook
cargo install mdbook

# Serve locally
mdbook serve

# Build the book
mdbook build
```

Then open `http://localhost:3000` in your browser.
